# 烬土前线 · 联合作战

React + Vite + Canvas 的桌面透视沙盘战棋。沙盘正向呈现，默认视角放大 15%，车辆模型缩小至原来的 72%。我方位于画面下方，向上推进，支持九个独立关卡（含三篇战史改编）和四套可选编队。

## 运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开 http://localhost:5173 ，在战区选择页部署部队。

```sh
npm test          # 规则、地图连通、回合状态与投影测试
npm run build    # 生成 dist/ 静态站点
npm run preview  # 预览正式构建
npm run test:e2e # 浏览器交互与移动端布局（默认使用本机 Google Chrome）
```

## 关卡与车辆

| 地图 | 推荐编队 | 地形路线 | 我方 / 敌方（困难） |
| --- | --- | --- | --- |
| 断脊山隘 | 均衡编组 | 中央山隘与北侧绕行公路 | 9 / 14 |
| 长风峡谷 | 机动编组 | 中部缺口与侧翼山道 | 9 / 16 |
| 双桥河湾 | 装甲编组 | 两岸由北桥与南桥连接 | 9 / 18 |
| 林海走廊 | 机动编组 | 西侧林道与东侧林缘 | 9 / 14 |
| 碎岩盆地 | 装甲编组 | 中央裂口与东侧坡道 | 9 / 16 |
| 环湖交锋 | 炮击编组 | 西堤与东堤绕湖推进 | 9 / 18 |

每关可选择「简单、容易、困难」，默认简单。简单档敌军数量为原版的一半、生命和火力约为 70%；容易档数量约为 75%、生命和火力约为 85%；困难档保留原版。第一关简单档为 7 辆敌军，重新部署保留当前难度。

每关可选择均衡、机动、装甲或炮击编组，均为 9 辆车。均衡编组为：侦察车 ×2、主战坦克 ×2、重型坦克 ×1、自行火炮 ×2、火箭炮 ×1、工程车 ×1；其他编组调整各车型数量。部署前可查看具体构成，重新部署保留当前编组。没有步兵或飞机。

每张地图采用不规则边界，设有不同的障碍与道路布局。切换部署会开启新战局；只返回地图选择页会暂停当前战斗，可继续返回。进入战场后，地址会变为 `/battle/关卡标识?difficulty=难度&formation=编队`。刷新或直接打开该地址，会按对应关卡、难度和编队重新开局，不保留位置、血量或回合。浏览器前进、后退可切换页面。部署到静态服务器时，需要将这些路径回退到 `index.html`（本地 Vite 已支持）。

## 战史改编关卡

新增阿拉曼突破（累计抵达两个集结点）、桥头救援（护送工程车，工程车全损则失败）、阿登守望（在观察点连续撑过四个敌方回合，离点会中断计数）。任务点以金色地格标出，战场简报显示进度、史实背景与战后结语。剧情地图需要达成任务目标，不能只靠全歼跳过任务。

史实参考：[第二次阿拉曼战役](https://www.nam.ac.uk/explore/battle-alamein)、[市场花园行动](https://www.nam.ac.uk/explore/market-garden)、[突出部战役](https://www.nps.gov/places/battle-of-the-bulge.htm)。地图、兵种、任务与对话为游戏改编，不是史实复原。

## 画面与战斗反馈

地表加入草石、水波和道路磨损，车辆增加装甲接缝与铆钉细节。开火依次呈现炮口闪光、弹道、后坐力、命中火花、烟尘及伤害数字；连续攻击的特效独立播放，迷雾射手只显示目标受击。系统启用「减少动态效果」时关闭震屏、后坐力和粒子运动，保留伤害信息。

## 战斗规则

- 每辆车每回合移动、开火各一次，顺序不限；工程车可用开火机会维修相邻友军 5 点生命。目标由玩家指定；所有存活车辆移动完后自动结束回合，剩余开火／维修机会会跳过，请在最后一辆车移动前完成，手动结束会跳过剩余行动。
- 山地、林地、河流、其他单位与地图外区域不可通行；桥梁和道路可通行。
- 侦察车移动 6 格、视野 5 格，其他车辆各有独立移动、视野、射程、生命与装甲数据。
- 我方共享实时视野；隐藏敌人不可攻击。敌方可以从迷雾内开火，受击效果不暴露射手。
- 直射被山林阻挡；自行火炮和火箭炮可越过山林，但分别有 2 格、3 格最小射程。
- 装甲抵消伤害，命中至少造成 1 点伤害；无友军误伤和反击。
- 敌方搜索全图可到达射击点，能沿山道绕行。简单档直接推进并在同分选项中变化路线；容易档更重视射击位置与薄弱、高价值目标；困难档优先集中攻击受损目标，工程车可主动接近维修，低血车辆会寻找威胁较小的位置。拥挤时单位等待道路腾出。
- 每次新部署生成独立的敌方选择种子，同等可行的选择可能不同；随机状态随撤回一起恢复，因此相同局面重做可复现。敌军初始部署仍由关卡定义。
- 歼灭全部敌军获胜，我方全灭则失败。

操作：点击车辆或编队选择，点击蓝色地格移动（浅橙虚线外沿表示火力范围）；点击可见敌军直接开火并查看情报，无需切换开火模式。选择工程车后切到维修模式，点击相邻受损友军。滚轮/按钮缩放；鼠标拖动、手机滑动、触控板双指横滑或左右箭头按钮平移，Shift＋滚轮也可横向平移。

点击棋盘下方「撤回」可恢复上一次成功移动、开火、维修或结束回合前的状态，最多保留最近 50 步。敌方行动中或行动结束后也可撤回；重新部署会清空记录。

## 模块结构

```text
src/
  App.jsx                    页面切换与布局
  components/                React 地图选择、战场、车辆面板、指南
  hooks/useGame.js            回合定时器及 React 生命周期清理
  game/
    catalog.js               六类车辆属性与编队
    scenarios.js             九个独立关卡与四套编队定义
    engine.js                移动、视野、攻击、维修、AI 与胜负规则
    reducer.js               不可变状态更新、战报、特效与会话隔离
  rendering/
    projection.js            桌面透视投影与地格坐标转换
    picking.js               车辆模型点击与悬停判定
    battlefield.js           Canvas 地形和六类车辆模型绘制
    combat.js                弹道、后坐力、命中烟尘与减弱动态效果
  styles.css                 响应式界面
 tests/                      Node 行为测试与 Playwright 浏览器测试
```

新增关卡时扩展 `scenarios.js`，无需改 UI；车辆数和敌军统计从关卡状态计算。`1.html` 是原有独立文件，未纳入新应用。
